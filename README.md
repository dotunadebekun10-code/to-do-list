# ✨ Premium React To-Do List

A modern, glassmorphic To-Do list built with React 19, Vite, and Tailwind CSS 4.0.

![Premium Design Preview](https://via.placeholder.com/800x450/0f172a/60a5fa?text=Premium+To-Do+List+Preview)

## 🚀 Features

- **Modern UI**: Sleek glassmorphic design with deep sapphire gradients.
- **Micro-animations**: Smooth transitions and interactive feedback.
- **Lucide Icons**: Professional iconography for a premium feel.
- **Responsive**: Works beautifully on all screen sizes.
- **Fast**: Powered by Vite and React 19.

## 🛠️ Tech Stack

- **Framework**: React 19
- **Build Tool**: Vite
- **Styling**: Tailwind CSS 4.0
- **Icons**: Lucide React

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone <your-repo-url>
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

## 🌐 Deployment

This project is optimized for deployment on **Vercel**.

1. Push your code to a GitHub repository.
2. Go to the [Vercel Dashboard](https://vercel.com/dashboard).
3. Click **"New Project"** and import your repository.
4. Vercel will automatically detect the Vite configuration.
5. Click **"Deploy"**.

The `vercel.json` file is already included to handle client-side routing and ensuring your app runs smoothly.
